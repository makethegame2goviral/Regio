# REGIO NEWS – Mobilität in der StädteRegion Aachen

Eine kleine, animierte Erklär-Sendung für euren Vortrag.

## Lokal ansehen
Öffnet `index.html` im Browser.

## Mit GitHub Pages veröffentlichen
1. Öffnet **Settings** im Repository.
2. Wählt links **Pages**.
3. Unter **Build and deployment** wählt **Deploy from a branch**.
4. Wählt Branch **main** und Ordner **/(root)** und speichert.
5. Nach der Veröffentlichung ist die Seite unter `https://makethegame2goviral.github.io/Regio/` erreichbar.

## Bedienung
- **Sendung abspielen**: wechselt automatisch durch die sieben Szenen.
- **Zurück / Weiter**: manuell durch die Szenen gehen.
- Klick auf einen Szenen-Chip: direkt zu einer Szene springen.
- Der Text unter **Das sagt ihr dazu** ist der passende Sprechtext für die jeweilige Animation.

Die Seite benötigt keine zusätzlichen Bibliotheken und passt sich an Smartphones und Tablets an.
